# Trade Radar Pro

A股短线交易雷达。当前版本为前端可部署骨架，数据层预留真实行情接口。

## V1 设计
- 市场情绪：涨停数、跌停数、炸板率、连板高度、晋级率
- 强势板块：涨停贡献、平均涨幅、成交额、持续性
- 连板雷达：按连板高度、封板质量、成交额、换手率排序
- 二波雷达：前期强势 + 回撤收敛 + 均线修复 + 放量突破
- 主升雷达：趋势、均线、量价、强度综合评分
- 风险过滤：ST、退市整理、异常波动、高位连续加速等

## 评分
总分 100：趋势 25、量价 25、强度 20、资金活跃 20、形态确认 10。

> 当前仓库不包含任何券商交易下单能力，仅用于行情分析与观察池。
